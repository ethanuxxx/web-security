  1. D.1JSON 的組成

JSON（JavaScript Object Notation）是用純文字表示結構化資料的格式，網站之間傳資料很常用。

D.1 JSON 的組成

下面是一份有兩個欄位的資料：

{ "username": "alice", "age": 25 }
  • 物件（object）：用大括號 { } 包起來的一組「鍵：值」，彼此用逗號分開。
  • 鍵（key）：資料的名稱，一定是用雙引號包起來的字串，例如 "username"。
  • 值（value）：鍵對應的內容，寫在冒號後面。
  • 字串（string）是雙引號包起來的文字，如 "alice"；值也可以是數字（25）或真假（true、false）。
  • 陣列（array）：用方括號 [ ] 包起來的一串值，例如 ["a", "b"]。

物件的值可以又是一個物件，這種結構稱為巢狀（nested）：

{ "username": "alice", "profile": { "admin": false } }

同一個鍵的值可以是字串，也可以是另一個物件。NoSQL 的查詢正是靠這個彈性：值的位置收到物件而不是字串，查詢的意思就跟著變。
