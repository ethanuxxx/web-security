附錄 A Shell

  2. A.2常見的 shell
  3. A.3網站與 shell 的關係

Shell 是接收命令、啟動命令所指定程式的程式。命令可以由人在終端機打進去，也可以由另一個程式以字串交給它。它位在人或程式與作業系統之間，負責啟動程式。

終端機視窗只負責顯示文字；讀取命令、啟動程式的是視窗裡執行的 shell。下面的命令打進終端機後，shell 讀取它，啟動列出目錄內容的 ls 程式，ls 的輸出再顯示在視窗中。

user@server:~$ ls reports
2026-09-01.csv
2026-09-15.csv
2026-10-01.csv

A.1 Shell 的用途

  • 執行程式與工具，例如查看目錄、轉換檔案、發出網路請求
  • 把多個步驟串成一件工作，前一步的結果交給後一步
  • 寫成腳本，讓重複的工作自動執行

A.2 常見的 shell

系統上有多種 shell。在 Linux 上，Python 的 shell=True、C 的 system() 等函式把命令字串交給系統執行時，啟動的是 /bin/sh；在 Debian、Ubuntu 上，/bin/sh 是 dash。人在終端機裡互動使用的通常是 bash。

A.3 網站與 shell 的關係

後端程式有時把一段命令字串交給 /bin/sh，藉此執行現成的工具，例如報表程式或圖片轉檔工具。程式也可以不經過 shell，直接啟動另一個程式。
