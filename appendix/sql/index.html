附錄 C SQL

本節內容

  1. C.1SELECT 查詢的結構
  2. C.2其他語句

SQL（Structured Query Language，結構化查詢語言）是網站跟資料庫溝通的語言。網站把一句 SQL 以文字交給資料庫，資料庫先讀懂這串文字（解析，parse），再照意思執行，最後回傳結果列。

C.1 SELECT 查詢的結構

最基本的查詢由三部分組成。下面這句從會員表取出住在 Taipei 而且點數大於 100 的會員：

SELECT * FROM members WHERE city = 'Taipei' AND points > 100

以會員表來說，會回傳 id 為 1 與 3 的兩列（林小雅、王美玲）。

  • SELECT *：取回哪些欄。* 表示每一欄。
  • FROM members：從哪張表查。
  • WHERE …：資料庫逐列檢查，只留下條件為真的列。
  • AND：兩邊都為真；OR：任一邊為真就行。

文字值用單引號圍住，資料庫把兩個單引號之間的內容當成資料；數字不加引號。

C.2 其他語句

除了查詢，還有 INSERT（新增一列）、UPDATE（修改既有的列）、DELETE（刪除列）。它們同樣是文字，同樣由資料庫解析後執行。UPDATE 與 DELETE 也用 WHERE 指定要動哪幾列。

資料庫怎麼解讀一句 SQL，決定了網站送出的每一句查詢實際做了什麼。
